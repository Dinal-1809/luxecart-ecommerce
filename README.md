
# LuxeCart

A modern and responsive e-commerce website featuring product listings, category filters, price range filtering, product search, sorting, ratings, and a clean, premium shopping interface.

## Features

- Product listings
- Product search
- Category filtering
- Price range filtering
- Product sorting and ratings

## Tech Stack

- React
- Vite
- CSS

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
